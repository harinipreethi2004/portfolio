# Harini N — Interactive Portfolio

This is a single-page, responsive portfolio created from the information in the supplied resume.

## Included
- `index.html` — portfolio structure/content
- `style.css` — responsive design, glassmorphism, animations, project visuals
- `script.js` — scroll reveal, cursor glow, progress bar, card tilt and mobile menu

## Run locally
1. Keep all three files in the same folder.
2. Double-click `index.html`, or open it with VS Code + Live Server.
3. No build step is required.

## Publish for a shareable link

### Option A — Netlify (simple)
1. Go to Netlify and sign in.
2. Choose **Add new site → Deploy manually**.
3. Drag the `harini_portfolio` folder into the upload area.
4. Netlify will give you a public `netlify.app` link.
5. You can rename the site under Site settings.

### Option B — GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Select the main branch and root folder.
5. Save and open the generated Pages URL.

### Option C — Vercel
1. Create a GitHub repository and upload the three files.
2. Import the repository into Vercel.
3. Deploy using the default settings.
4. Vercel gives you a public URL.

## Add a real profile photo
The current hero uses a clean `Harini` name treatment instead of inventing a portrait. If you want Harini's actual photo, add an image file and replace the `.avatar` block in `index.html` with an `<img>` element.

## Resume source
The content is based on the supplied one-page resume: education, skills, internship, projects, certifications, contact details and achievements.
